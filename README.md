# Projeto Java - Iniflex

Projeto desenvolvido para o teste prático de programação da Iniflex.

## Tecnologias

- Java 17
- Programação Orientada a Objetos
- Java Stream API
- Collections
- LocalDate
- BigDecimal

## Funcionalidades

- Cadastro dos funcionários
- Remoção do funcionário João
- Formatação de datas e valores
- Aplicação de aumento salarial de 10%
- Agrupamento por função
- Filtro de aniversariantes
- Identificação do funcionário mais velho
- Ordenação alfabética
- Cálculo do total de salários
- Cálculo da quantidade de salários mínimos

## Estrutura do Projeto

```text
src/
└── main/
    └── java/
        ├── model/
        │   ├── Pessoa.java
        │   └── Funcionario.java
        └── Main.java
```

## Como executar

Requisitos:
- JDK 17+

Execute a classe Main.java.
